# Коміт у трекері звичок

Виконуй кроки строго по порядку. Якщо крок провалився — зупинись і повідом, коміт не роби.

1. **Подивись стан.** Виконай `git status --short` і `git branch --show-current`. Якщо змін немає — скажи «Нічого комітити» і завершуй.

2. **Перевір заборонені файли.** У змінах не має бути `.env`, `habits.db` чи `habits.db.*`. Якщо є — зупинись і назви файл.

3. **Прогони перевірки лише для зачеплених частин:**
   - змінено `*.py` → `PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe -m pytest -q`
   - змінено `frontend/` → у `frontend/`: `npx tsc --noEmit`, потім `npm test -- --run`
   - змінено лише документацію чи `.github/` → перевірки пропусти, скажи про це

4. **Додай файли поіменно** (`git add <шлях>`), ніколи `git add -A` чи `git add .`.

5. **Напиши повідомлення коміту українською:**
   - перший рядок — до 72 символів, формат `Область: що змінилось` (приклад: `Бот: вибір розкладу при створенні звички`);
   - порожній рядок;
   - 2–5 пунктів `- ` про **чому**, а не лише що;
   - останній рядок: `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.

   Передавай повідомлення через `git commit -F -` з heredoc.

6. **Не пуш.** Пуш — лише якщо користувач прямо попросив «запуш».

7. **Звіт користувачу — рівно три рядки:**
   - хеш і перший рядок коміту;
   - результат перевірок (напр. `pytest 276 ✓, Vitest 116 ✓, tsc ✓`);
   - гілка і чи запушено.
